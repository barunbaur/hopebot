# 🌻 HopeBot: An Uplifting AI Wellness Companion

**HopeBot** is a gentle, empathetic AI chatbot designed to support mental wellness, encourage gratitude, and provide hopeful perspectives during stressful moments. Built with a focus on positive, human-centric technology, it helps users reframe challenges into manageable, uplifting steps.

## 🌟 Why I Built This
As a freelance digital creator, I believe technology should be a force for hope and empowerment. I built HopeBot to explore how Large Language Models can be guided (via careful prompt engineering) to provide non-judgmental, comforting, and actionable support, rather than just raw information.

## 🛠️ Tech Stack
- **Frontend**: Streamlit (Python) for a clean, calming, and accessible user interface.
- **AI Engine**: Groq API (powered by high-speed open-weight models) for rapid, empathetic text generation.
- **Design**: Custom CSS for a warm, soothing color palette to enhance the user's sense of calm.

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/your-username/hopebot.git`
2. Install dependencies: `pip install streamlit groq`
3. Get a free API key from [Groq Console](https://console.groq.com/).
4. Run the app: `streamlit run app.py`
5. Enter your API key in the sidebar and start chatting!
